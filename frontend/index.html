Laboratorio de Reglas de Negocio en Vivo

Ejecuta llamadas de prueba para observar cómo Spring Boot valida las reglas de negocio y cómo el GlobalExceptionHandler responde con códigos HTTP 400 y 404.

1. Anticipación Mínima (1 hora a futuro)

HTTP 400

Intenta agendar una cita con fecha de hace 10 minutos. Spring Boot rechazará la petición mediante ReglaDeNegocioException.

2. Conflicto de Horario (Anti-Solapamiento)

HTTP 400

Intenta agendar dos citas con el mismo especialista en la misma fecha y hora. Se disparará la regla de conflicto de agenda.

3. Monto de Pago Insuficiente

HTTP 400

Intenta registrar un pago con un monto menor al precio oficial del servicio contratado ($1.00 en vez de la tarifa oficial).

4. Doble Pago (Unicidad 1 a 1)

HTTP 400

Intenta registrar un segundo pago a una cita que ya fue pagada. La relación 1 a 1 impedirá duplicidades.

5. Recurso Inexistente

HTTP 404

Busca una cita con el ID 999999 que no existe en el sistema.
